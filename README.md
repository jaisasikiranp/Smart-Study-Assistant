# Smart-Study-Assistant

## 📌 Description
This project is an AI-powered Smart Study Assistant that helps students manage tasks, notes, and study planning.

## 🚀 Features
- Voice assistant
- Task management
- Study planner
- Notes system
- Backend API

## 🛠️ Technologies Used
- Python
- Flask (Backend)
- SQLite

## ▶️ How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run the app:
   python backend/app.py

## 📂 Project Structure
- assistant/ → AI assistant logic
- backend/ → API routes
- automation/ → automation features
- database/ → database handling
